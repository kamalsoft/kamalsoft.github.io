Questions and answers

What is Agent Skills Hub?
An open-source collection of skills for software engineers who work with coding agents. Each skill is a folder with a SKILL.md file that tells the agent what to check, in what order, and what to report.
Do I need an API key or a licence key?
No. The skills make no model calls and need no key. The agent you use sends the code it reads to its own model provider, under your own subscription.
How do I get the skills?
Open the Skill Advisor, choose the areas or skills you need, and select Get my skills. You receive one zip. A single skill can also be fetched from its own page, as a zip named after the skill.
Where do the skills go in my project?
Unzip at the project root, so each skill lands in .github/skills/<skill>/. GitHub Copilot reads them from there. Other agents read their own folder, for example .claude/skills for Claude Code.
Does unzipping change my code?
It only writes skill folders. It overwrites any file with the same name, so keep a copy of a skill you have edited before you unzip a newer version over it.
How do I update a skill?
Get the newer zip and unzip it over the old one. Your edits to the replaced files are lost, so apply them again afterwards.
Do the skills run code?
Some skills include helper scripts, such as a Python file that splits a large folder into chunks. The agent runs them on your machine when a skill asks for them. Read a script before you let an agent run it.
How are the grades decided?
Each skill is scored 1 to 5 on five criteria, and the weighted score sets its grade. The grades are design grades, not measured results. The Grades page shows the criteria and the worked example.
Does the site collect my data?
The site serves static files. It never receives your code, and your skill selections are not sent anywhere. The hosting service keeps its usual request logs.

Before you rely on the output

  • The skills are a technical aid. They are not legal, security, privacy, compliance or audit advice.
  • Agents can miss real problems and report problems that do not exist. Check every finding against the source.
  • Compliance skills report whether evidence is present. They do not certify compliance.
  • The agent sends the code it reads to its model provider. Do not use the skills on material you may not send there.
  • The software is provided as is, without warranty, under the MIT licence.
