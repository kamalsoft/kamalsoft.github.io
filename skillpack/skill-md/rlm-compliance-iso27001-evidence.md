# ISO 27001 evidence review

ISO 27001 evidence review: which Annex A controls the code and pipeline can evidence, and the gaps. Read the code or data before you judge it, and do not change files unless the user asks for a fix.

## Protocol

1. **Confirm the scope.** The controls in scope as the user states them.
2. **Map evidence.** List the code, configuration and pipeline evidence for each control.
3. **Check the records.** Each control needs dated, retrievable evidence.
4. **Flag gaps.** Controls with no evidence in the repository.
5. **Report.** Each control with its evidence status and what must be collected elsewhere.

## Post-production

- **Undated evidence** is treated as missing. Date each record.
- **Gaps found in audit** cost a re-audit. Check the controls before the visit.

## Not checked

Runtime behaviour under load, and anything outside the files, data or export the user gave.
