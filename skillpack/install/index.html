Install

How to install

Two steps. Install the extension once, then install the skills into each project that uses them.

Step 1: install the extension

The extension is not on the VS Code Marketplace yet. Download the latest package, then install it.

Download skill-pack-2.3.0.vsix

code --install-extension skill-pack-2.3.0.vsix

In VS Code, open the Extensions view (⇧⌘X), choose Install from VSIX… from the … menu, select the file, and reload if asked.

Step 2: install the skills into a project

  1. Open the project as a folder (File > Open Folder), not a single file.
  2. Run RLM: Install Agent Skills from the Command Palette (⇧⌘P on macOS, Ctrl+Shift+P on Windows).
  3. Answer the three questions below, then wait for the message RLM: wrote N file(s).
QuestionDefaultWhat to choose
How should the helper scripts run?1. Python1 if Python 3 is available. 2 if only Node.js is available. 4 if programs may not run. Option 3 does not work in the standard package (see below).
Where should the skills go?GitHub CopilotEvery agent you use. You can pick more than one.
Which skills should be selected?Fourteen selectedKeep the defaults, or tick the off ones you need (the three compliance skills, release-notes, stack-auditor, trust-layer-validator, incident-postmortem).

About option 3, Portable Python. The portable interpreter adds about 22 MB, so the standard package leaves it out. Choosing option 3 stops the install with the message “the portable Python runtime is not bundled in this build”. Choose option 1, 2 or 4 instead.

Step 3: check the install

  • GitHub Copilot: open Copilot Chat and type /skills. The rlm-* skills should be listed.
  • Claude Code: the skills are in .claude/skills/. Name a skill in your request.

Then ask your agent in plain words, naming the skill:

Use the rlm-security-audit skill on src/. Report findings with file and line.

Update the extension

Download the newer .vsix from the binary folder of the repository and install it over the old one.

code --install-extension skill-pack-2.3.0.vsix --force

Then run RLM: Install Agent Skills again in each project, to refresh its skills. Files you have edited are left alone.

Uninstall the extension

If you entered a licence key, run RLM: Remove Licence Key first, so the key does not stay in VS Code's secret storage.

code --uninstall-extension kamalsoft.skill-pack

Quit VS Code completely and start it again. A window reload is not enough: VS Code removes uninstalled extensions only on a full restart.

To check that nothing is left, this command should print nothing:

code --list-extensions --show-versions | grep kamalsoft

Uninstalling the extension does not touch your projects. To remove the skills, delete the skill folders it wrote (for example .github/skills/rlm-security-audit/) and the memory store .agent-memory/.

Commands

In VS Code, from the Command Palette (⇧⌘P on macOS, Ctrl+Shift+P on Windows):

CommandWhat it does
RLM: Install Agent SkillsInstalls or updates the skills in the open project. Asks how helpers run, which agents, and which skills.
RLM: Enter Licence KeyChecks a key offline and stores it in VS Code’s secret storage on this machine. Unlocks pro or premium skills in every project.
RLM: Remove Licence KeyDeletes the stored key. Essentials skills keep working.

Older copies. Earlier builds were published as kamalsoft.rlm-agent-skills and kamalsoft.vscode-rlm-agent. If either is still installed, uninstall it the same way, then restart VS Code.
