What a skill is

A folder with a SKILL.md file, optional scripts, references and assets. Agents load it when it matches the task.

Installing skills

Install the extension, then pick the skills for each project. Skills that need a licence key are marked by tier.

How grades work

Each skill is scored on support, importance, severity, usage and presence. The grade sets its tier.
